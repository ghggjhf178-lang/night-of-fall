ليلة السقوط — نسخة Vercel الآمنة
================================

هذه النسخة تستخدم Vercel Function لإخفاء مفتاح API-Football عن المتصفح.
لا يوجد مفتاح API داخل index.html. لا تضع المفتاح في أي ملف ترفعه إلى GitHub.

طريقة النشر:
1) سجّل الدخول إلى Vercel وأنشئ مشروعًا جديدًا باستيراد مستودع GitHub يحتوي هذه الملفات.
   يجب أن تكون index.html و vercel.json في جذر المشروع، ومجلد api/ يحتوي football.js.
2) داخل مشروع Vercel افتح Settings > Environment Variables.
3) أضف متغيرًا باسم API_FOOTBALL_KEY وضع المفتاح الجديد كقيمة. فعّله لبيئة Production (وPreview إذا تحتاج).
4) احفظ ثم أعد نشر المشروع (Redeploy) حتى يُقرأ المتغير.
5) افتح رابط الموقع المنشور. سيحاول الموقع جلب مباريات تاريخ اليوم تلقائيًا.

تنبيه أمني:
- المفتاح الذي انكشف في محادثة سابقة ينبغي إلغاؤه/تدويره قبل وضع المفتاح الجديد في Vercel.
- الخادم الوسيط لا يكشف المفتاح في استجابات المتصفح، ويقبل فقط مسارات المباريات المسموحة ويخزّن النتائج مؤقتًا على CDN لتقليل استهلاك الحصة.
- لأن الموقع عام ولا يتطلب تسجيل دخول، يلزم إعداد Rate Limiting على /api/football من لوحة Vercel Firewall إن كان متاحًا في خطتك، ومراقبة حصة API-Football. التخزين المؤقت وحده ليس حماية كاملة من إساءة الاستخدام.
- لا ترسل مفتاح API في المحادثة ولا تضفه إلى ملفات المشروع.

اختبار محلي:
فتح index.html مباشرة كملف (file://) لن يشغّل API؛ يجب تشغيل المشروع عبر Vercel أو بيئة تطوير Vercel مع متغير البيئة API_FOOTBALL_KEY.
